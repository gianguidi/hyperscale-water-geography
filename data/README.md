# Data directory

Place local input data under `data/raw/`.

Do not commit restricted facility-level data, exact coordinates, addresses, or vendor-provided raw files unless they are explicitly cleared for public release.

The notebook expects these paths by default:

```text
data/raw/facilities.csv
data/raw/BA_egrid.xlsx
data/raw/balancing_authorities_polygons/balancing_authorities_EPA.shp
data/raw/hydrobasins/hybas_lake_na_lev06_v1c.shp
data/raw/aqueduct/Aqueduct40_baseline_monthly_y2023m07d05.csv
```
